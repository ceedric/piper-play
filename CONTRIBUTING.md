# Joining in 🌱

Thank you for being here. You don't need to know how to code to help.

## Ways to help (no code needed)

- **Tell me where you got stuck.** If a step in the README confused you, that's a problem with the README, not with you. [Ask for help](../../issues/new/choose) and I'll make it clearer for the next person.
- **Share what you made.** Hearing your piece helps others imagine what's possible.
- **Share pronunciation tricks.** If you found a spelling that makes Piper say a word right, especially names and words from your language, you're welcome to share it (only if it's yours to share).
- **Translate the guide** into another language.

## If you want to change the code

1. Open an issue first and say what you'd like to change, so we can talk about it.
2. Keep changes small and explained in plain language.
3. Remember who this is for: people who may be opening a terminal for the first time. Simple beats clever.
